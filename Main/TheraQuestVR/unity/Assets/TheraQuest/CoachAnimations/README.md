# Coach Idle Animations

Drop optional looping humanoid idle animations here (e.g. from Mixamo).

### Suggested Animations
- **Breathing Idle** (Mixamo)
- **Idle Neutral** (Mixamo)

When an AnimationClip is placed in this folder, `HumanoidCoach` will automatically detect it and use it for gentle breathing and natural posture shifts when the character is standing.
